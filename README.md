# MyOS

A hobby operating system built from scratch.

## About

MyOS is an experimental operating system project written primarily in assembly language.

The goal is to learn how computers boot and how an operating system works, starting from the basics.

## Current Progress

- [o] Boot sector created
- [o] Booted in QEMU
- [o] Displayed `Hello World!` using BIOS
- [ ] Keyboard input
- [ ] More features to come!

## Development Environment

- Assembly: NASM
- Emulator: QEMU
- Host OS: Windows
